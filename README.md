# Vector DB — 15 Day Challenge

I'm a second-year Computer Science student, and I recently realized I knew almost nothing about vector databases.

So I decided to change that.

This is my **15-day learning challenge** where I'm trying to understand vector databases by actually using them, breaking things, experimenting, and documenting what I learn.

I'm not following this as a "build 15 projects in 15 days" challenge.

The goal is to understand the concepts properly.

---

## What I'm learning

I'll be exploring things like:

* embeddings
* vector similarity
* semantic search
* vector databases
* indexing
* metadata filtering
* hybrid search
* pgvector
* RAG
* retrieval and evaluation

The exact direction might change as I learn more.

---

## How this repo works

Each day has its own folder.

```text
phase-1-foundations/
│
├── day-01-first-vector-db/
├── day-02-embeddings/
├── day-03-...
└── ...
```

Each folder contains the code I worked on that day and a small README explaining what I understood.

I'm keeping the explanations simple because this repository is also meant to be something I can come back to later.
